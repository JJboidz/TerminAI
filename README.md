💻 TerminAI

TerminAI is a lightweight Linux terminal project built with Bash that opens a compact AI-powered coding window using the ChatGPT coding model.

The goal of the project is simple:

Help developers learn faster, solve problems, and improve coding skills directly from their Linux environment.

🚀 Features
Lightweight Bash-based launcher
Opens a small focused coding/chat window
Uses the ChatGPT coding model for programming assistance
Great for:
Learning new programming concepts
Debugging code
Generating snippets
Understanding errors
Improving workflow and productivity
🐧 Platform
Linux only
Built primarily using Bash scripting
📦 Usage
Clone or download this repository
Make the script executable:
chmod +x terminai.sh
Run the launcher:
./terminai.sh
🎯 Purpose

TerminAI is designed as a simple AI coding companion that stays accessible without needing a full browser window open all the time.

It focuses on:

Faster coding help
Cleaner workflow
Learning while coding
Minimal distractions
